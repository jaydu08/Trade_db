# 2026-11-11 独立市场广度备用源

## 故障与策略

Eastmoney 全量市场枚举返回 HTTP 502，CN/HK/US 当日 breadth 为空。原来只有该单一供应商；不能用 TrendSeedPool、日榜 Top 或用户清单代替全市场。

现在按以下顺序自动选择：

1. Eastmoney 完整枚举 + 同交易日有效报价；分页失败、HTTP 错误或有效覆盖不足都触发回退。
2. 已保存的独立完整报价帧广度。只匹配请求的完整交易日，不以“今天重新读了一次”改变原采集时间。
3. 从完整 Asset 资产目录去重后批量读取腾讯独立报价。逐证券核验日期、收盘时刻、正价格、有限涨跌幅、来源，并排除旧日期、盘中、无时间、别名冲突。不写入或改变资产目录。
4. 均失败时保留 null，列出实际尝试和失败原因。绝不填 0、复制其他交易日或用候选池外推。

Heatmap 取得完整行情后、任何筛选/市值/涨幅/TG quota 限制前保存 `data/agent_breadth/{market}/{session}.json`。保存失败不改变行情推送流程。美股在新纽约交易日开盘后，不允许用当天盘中涨跌冒充前一日广度；此时必须用已存盘后样本。香港 2026 年已公告半日市复用现有日历日期，按半日收盘校验。

## 口径与时间

- 备用统计是完整资产目录报价获取链路中，真正有可核验同一完整交易日报价的证券数，不是交易所认证的全市场总数。
- 保留 `is_all_market_total=false`、`quality=partial`、`coverage_scope`、`includes`、`requested_universe_count`、`enumerated_count`、`covered_count`、`coverage_ratio_basis`、排除原因、目录版本哈希及实际来源。
- 资产目录可能包含 ETF、ADR、权证、权利等产品，不能将其解释为“纯普通股全市场统计”。原始目录可能漏项，coverage_ratio 只相对该明确目录计算；不能解释为覆盖全交易所的百分比。
- 每个市场保留真实 `session_date`、行情 `observed_at/data_asof`、原采集 `source_checked_at` 和来源尝试 `source_attempts`。读取已完成交易日缓存的时间单独为 `read_at`。
- 本次恢复 US 原始应用缓存时，原 HTTP 完成时间没有单独存储，采用原缓存成功写入时刻作为采集完成上界，并在 `source_checked_at_basis` 明示，不把恢复时间冒充原采集时间。原完整可信缓存已另行备份。
- 已存在但 breadth 缺失的短期 context 缓存不再抑制回退，成功 context 按新版 pipeline 复用。
